# Типы локальных экономик МО: данные и журнал экспериментов

Цель - выделить типы локальных экономик муниципальных образований (МО) и проследить, как они меняются во времени.

Итог: `clustering.ipynb`, 1569 МО, 52 признака, четыре типа - сырьевые районы, ядра агломераций, промышленные города, аграрная периферия. Комментарии с метриками в разделе 13 ноутбука.

## Лог исследования

**1. Кластеризация только по тратам** 1952 МО x 24 месяца x 5 категорий, пять мер близости (евклид, DTW, корреляция, лаговая корреляция, косинус), шесть методов, 287 конфигураций. Устойчивых типов не нашлось: силуэт 0,16-0,44, устойчивость 0,48-0,70, ARI между лучшими разбиениями разных мер ниже 0,3.

**2. Разбор причин неудачи** Главная ось различий оказалась одна - уровень трат, связанный с урбанизацией, и автовыбор взял HDBSCAN с 83% МО в шуме. Три причины: сеть из взаимных kNN распалась на 69 компонент и графовые методы не проверились, доля шума не входила в фильтр вырожденности, дублирующие признаки усиливали ось уровня.

**3. Побочные результаты первого эксперимента** DTW на уровнях повторил евклидово расстояние (96% общих ближайших соседей) при в сотни раз большем времени счёта, а лаговая корреляция повторила обычную (ранговая корреляция матриц 0,94) - опережений между МО на месячном шаге нет. Обе меры из дальнейшей работы исключены.

**4. Добавление признаков** Траты по пяти категориям описывают размер МО и мало что сверх него, поэтому понадобились отраслевая структура, демография, инфраструктура и география.

**5. Выбор источников** Из публичных данных по МО отобраны три, которым можно доверять на этом масштабе: БДМО Росстата (отраслевая структура, уровень жизни, инфраструктура), границы МО (пространственное положение) и глобальные растры (единая методика по всей стране там, где Росстат скрывает показатель).

**6. Лоадеры в `datasets/`** Для каждого источника отдельный модуль, возвращающий таблицу с индексом по ОКТМО. БДМО читается по каталогу tochno.st, коды показателей зафиксированы в реестре `INDICATOR` вместо поиска по названиям, чтобы состав признаков не менялся от правки формулировки в каталоге.

**7. Мэтч МО между источниками** В тратах СберИндекса нет кодов ОКТМО, только названия, поэтому сопоставление идёт по сокращённому названию с границами. МО, у которых сокращённое название неоднозначно (два Александровских района в разных регионах), отбрасываются (226 из 2118).

**8. Ошибки в загрузчике БДМО** Выбирался последний год, а он частичный, пропуски в разрезах считались неизвестными вместо нулей, вложенные группы ОКВЭД суммировались вместе с разделами, в которые входят

**9. Фильтр МО по заполненности** 286 МО не имеют данных Росстата. После заполнения медианой они становились одинаковыми "средними МО" и склеивались в кластер, которого в реальности нет, поэтому МО с заполненностью ниже половины признаков исключаются.

**10. Каркас `clustering.ipynb`** Два прогона на одном каркасе: A - только статичные признаки, B - статика плюс траты (B1 признаками из рядов, B2 комбинированным расстоянием с сеткой λ). Шесть методов, k от 2 до 15, четыре индекса (SW, CH, S_Dbw, MQ) плюс устойчивость на подвыборках 80%.

**11. Интерпретация вместо важности признаков из модели** Permutation importance на обучающей выборке давала нули. Заменил на критерий Краскела-Уоллиса - долю различий по признаку, объяснённую типом, которая считается без модели.

**12. Перевес географией других признаков** Координаты центроида и код региона попали в признаки и разрезали карту по долготе. Убраны из входных.

**13. Недочет по масштабированию** `RobustScaler` делит на межквартильный размах, а у разреженных отраслевых долей (три четверти МО около нуля) он почти нулевой. Одна доля растянулась в сотни раз, пороги дерева по ней доходили до 448 при том, что доля не может выйти за 1, и четыре типа из девяти оказались её градациями. Заменил на `StandardScaler`

**14. Перевес административного статус** Флаг "центр региона" объяснял 0,958 различий - больше любого экономического признака - и сам задавал один из типов. Перенесён из входных признаков в проверочные: теперь без подсказки 63 центра из 74 попадают в промышленные города и отдельной группы не образуют

**15. Порог вырожденности** При минимальном размере кластера 1% выборки - спектральный метод и Louvain выбывали целиком, они выделяют маленькие группы. Снижение до 0,5% вернуло их в сравнение, и в текущем прогоне невырожденные разбиения дают четыре метода из шести.


## Заметки по данным

- Главная ось различий между МО - доля обрабатывающих производств: 0,662 различий по отгрузке и 0,544 по занятости
- Помесячные траты мало добавляют к статике: в сетке λ устойчивость падает монотонно по мере роста веса рядов (0,95 → 0,59), а состав групп меняется сильно (ARI с λ = 0 падает до 0,15)
- Доля нераскрытой отгрузки работает как признак аграрной периферии, поскольку Росстат скрывает значение там, где мало предприятий. Внутри самого крупного типа (831 МО, 53% выборки) структура из-за этого остаётся нераскрытой
- Резких границ между типами в данных нет: силуэт 0,121 при устойчивости 0,96. Разбиение воспроизводимое, но МО переходят друг в друга непрерывно
- HDBSCAN вырожден при всех настройках: областей достаточно разной плотности в этих данных нет.
